# Prompt: Reel Script (Instagram / YouTube Shorts)

**Purpose:** Write short-form video scripts built for how people actually watch —
hook-first, fast-paced, structured for on-camera delivery, not read like an essay.

## Required Reading Before Writing

1. `inputs/current-topic.md` or `inputs/property-details.md` — what the Reel is about
2. `knowledge/voice.md` — especially the "Instagram Reel script" voice-by-channel note
3. `knowledge/audience.md` — who this Reel needs to stop mid-scroll for
4. `knowledge/approved-examples.md`

## The 3-Second Rule

The first line has to earn the next 3 seconds of attention or nothing else in the script
matters. Do not open with a generic greeting, a slow establishing shot description, or
"Hey guys." Open with the sharpest, most specific line in the whole piece — a real
insight, a real number (sourced), a bold direct statement, or a genuine question the
viewer is actually asking themselves.

## Script Structure

```
**HOOK (0:00–0:02)**
[Spoken line — the single sharpest sentence in the script]
[On-screen text: short punch version of the hook, 5–8 words max]

**SETUP (0:02–0:06)**
[One line establishing what this Reel is actually about]

**BODY (0:06–0:XX)**
[3–5 beats, each one a single clear idea. For each beat, include:]
- Spoken line
- On-screen text cue (if different from spoken line)
- Visual/shot direction (what's on screen — property footage, Glen to camera,
  b-roll, text overlay, etc.)

**PAYOFF / CTA (final 3–5 seconds)**
[Spoken line delivering the CTA]
[On-screen text: the CTA, short and specific]

**Suggested caption pairing:** [one line — the caption doesn't repeat the script, it
adds context or a follow-up thought]
**Suggested audio/music direction:** [INFORMATION NEEDED unless Glen has a standing
preference — trending audio vs. voiceover-only vs. specific track]
**Estimated length:** [target 20–45 seconds for most Reels; note if this one is meant to
run longer]
```

## Rules Specific to This Format

- Write for the ear, not the eye — short clauses, no subordinate-clause-heavy sentences.
  Read every line out loud while drafting.
- No more than one idea per beat. If a beat needs two sentences to explain, it's
  actually two beats.
- Never invent a number, spec, or claim to make a beat punchier — pull from
  `inputs/property-details.md` or `inputs/market-data.md`, or flag
  `[INFORMATION NEEDED]`.
- On-screen text should never just repeat the spoken line verbatim — it should
  reinforce or compress it, since some viewers watch muted.
- End with one CTA, not three. Pick the single action that matters most for this piece
  (from `inputs/current-topic.md`'s stated goal).

## Output

Save to `outputs/reels/YYYY-MM-DD-[topic-slug].md` (or
`outputs/listings/[address-slug]/reel-script.md` if this is part of a listing launch).

## Quality Checklist

- [ ] Hook line would actually stop a scroll — read it out loud, cold, and ask if it's
      genuinely sharp
- [ ] No banned phrases from `knowledge/voice.md`
- [ ] No invented facts
- [ ] Single, clear CTA
- [ ] Script reads naturally when spoken aloud, not like written prose
