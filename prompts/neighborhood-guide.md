# Prompt: Neighborhood Guide

**Purpose:** Build authority content around Fort Lauderdale, Las Olas, Las Olas Isles,
Rio Vista, Sunny Isles, and Miami — the content that earns trust with relocation buyers
and lifestyle-driven buyers long before they're ready to transact.

## Required Reading Before Writing

1. `knowledge/markets.md` — the structural framework for each neighborhood
2. `knowledge/audience.md` — which persona this guide is really for (a relocation-buyer
   guide to Las Olas reads differently than a boating-buyer guide to Las Olas Isles)
3. `inputs/market-data.md` — for any statistic used
4. `knowledge/voice.md`

## Steps

1. Pick one neighborhood and one persona angle per guide — resist the urge to write one
   generic "everything about Fort Lauderdale" piece. Specific beats comprehensive.
2. Choose an angle that isn't purely descriptive — a neighborhood guide is stronger as
   an answer to a real question the persona is actually asking:
   - "What's it actually like living on Las Olas day to day?"
   - "What does a New Yorker need to know before buying in Rio Vista?"
   - "Fixed bridge vs. no fixed bridge in Las Olas Isles — why it matters"
   - "Sunny Isles vs. Miami — which luxury condo market fits you?"
3. Structure:
   - Open with the real question or tension, not a geography lesson ("Fort Lauderdale is
     located in Broward County..." is a non-starter).
   - Cover lifestyle, character, and practical considerations using the framework in
     `knowledge/markets.md`.
   - Include real data where relevant, sourced from `inputs/market-data.md` — flag
     `[INFORMATION NEEDED]` for anything not yet logged.
   - Close with a specific next step (not just "contact me" — e.g., "if you're deciding
     between Las Olas and Rio Vista, I can walk you through both in one afternoon").
4. Produce in whichever formats are needed: blog post (deepest version), Instagram
   carousel (visual highlights), Reel script (fast-paced version), email (personal
   version for relocation-segment subscribers).

## Output Location

Save to `outputs/daily/` (if a single-format piece) or create a dedicated file per guide
under `outputs/weekly/` if part of a themed content week; use naming convention
`YYYY-MM-DD-[neighborhood]-guide-[format].md`.

## Quality Checklist

- [ ] Answers a specific real question, not a generic geography overview
- [ ] Written for one named persona, not "everyone"
- [ ] Any data point sourced from `inputs/market-data.md`
- [ ] No invented landmarks, comps, or claims about schools/safety/rankings
- [ ] Ends with a specific, low-pressure next step
