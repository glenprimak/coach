# Raw Notes

A freeform scratchpad for anything that hasn't been organized yet — voice memo
transcripts, quick thoughts, a client conversation worth turning into content, an
observation from a showing, a screenshot description, a half-formed idea. Nothing here
needs to be polished.

**How this gets used:** before starting a new content piece, skim this file for material
worth pulling into `inputs/current-topic.md`. Once a note has been turned into content
(or filed into the right knowledge/input file), move it to the "Processed" section below
or delete it so this file stays useful rather than becoming a junk drawer.

Treat everything here as raw and unverified — a note like "I think the new tower is
80% sold" is a lead to verify, not a fact to publish. Anything from this file that ends
up in content still has to be confirmed and, if numeric, logged properly in
`inputs/market-data.md` or `inputs/property-details.md` first.
