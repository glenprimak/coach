# Market Data

The single source of truth for any market statistic used in content. This system must
never cite a market figure that isn't logged here with a source and date. See
`knowledge/compliance.md` and `knowledge/markets.md` for why this matters.

**Rule:** every number below needs a source and a "data as of" date. A number without a
source should not be used in content — treat it as `[INFORMATION NEEDED]` until sourced.

## How to Add Data

```
### [Neighborhood/Area] — Data as of [Date]

**Source:** [MLS, Florida Realtors, brokerage report, etc.]

- Median sale price: [INFORMATION NEEDED]
- Median list price: [INFORMATION NEEDED]
- Active inventory (# of listings): [INFORMATION NEEDED]
- Months of supply: [INFORMATION NEEDED]
- Average days on market: [INFORMATION NEEDED]
- Year-over-year price change: [INFORMATION NEEDED]
- Closed sales (trailing period): [INFORMATION NEEDED]
- List-to-sale price ratio: [INFORMATION NEEDED]
- Notable trend/observation: [INFORMATION NEEDED]
```

## Data Hygiene Rules

1. Every entry needs a source and date — no exceptions.
2. Re-verify data older than 60–90 days before reusing it in new content; markets move
   fast, especially in the current condo/insurance environment.
3. When a prompt needs a number that isn't here, insert `[INFORMATION NEEDED]` in the
   draft and note exactly what's needed (e.g., `[INFORMATION NEEDED: current median DOM
   for Las Olas Isles]`) rather than pulling a number from general knowledge or an old
   memory of the market.
4. Delete or archive stale entries rather than letting outdated numbers linger and get
   accidentally reused.
