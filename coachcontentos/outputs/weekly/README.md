# Weekly Outputs

Weekly content calendars from `prompts/weekly-calendar.md` and periodic reviews from
`prompts/performance-review.md`.

**Naming convention:**
- Calendars: `YYYY-MM-DD-week-of.md` (Monday of that week)
- Performance reviews: `YYYY-MM-DD-performance-review.md`

Use this folder to see the plan before diving into the individual generated pieces,
which live in `outputs/daily/`, `outputs/listings/`, `outputs/reels/`,
`outputs/emails/`, and `outputs/market-updates/`.
