# Email Outputs

Newsletters, listing announcement emails, and lead-nurture sequences generated by
`prompts/email-campaign.md` and `prompts/lead-nurture.md`.

**Naming convention:**
- Single emails: `YYYY-MM-DD-[type]-[topic-slug].md`
- Nurture sequences: `nurture-[sequence-type]-[persona-slug].md`

Listing announcement emails that are part of a full listing launch live in
`outputs/listings/[address-slug]/email-announcement.md` instead.
