# Market Update Outputs

Content generated by `prompts/market-update.md`, always sourced from
`inputs/market-data.md`.

**Naming convention:** `YYYY-MM-DD-[area-slug].md`

Example: `2026-07-22-las-olas-isles.md`

Each file should include the headline finding, source and date of the underlying data,
the persona/angle it's written for, and the generated content in whichever formats were
requested.
