# Daily Outputs

Finished, ready-to-post content generated by `prompts/daily-content.md` (and
single-format pieces from `prompts/neighborhood-guide.md` when not part of a themed
weekly set).

**Naming convention:** `YYYY-MM-DD-[format]-[topic-slug].md`

Example: `2026-07-22-instagram-caption-las-olas-isles-no-fixed-bridge.md`

Each file should start with a one-line header noting the persona and goal it was built
for, per `prompts/daily-content.md`.
