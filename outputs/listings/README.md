# Listing Outputs

Full listing-launch campaigns generated by `prompts/listing-launch.md` and
`prompts/property-description.md`.

**Naming convention:** one subfolder per property, `outputs/listings/[address-slug]/`,
containing:

- `00-campaign-plan.md` — the overall sequence/timing plan
- `property-description.md` — MLS and narrative versions
- `reel-script.md`
- `carousel.md`
- `caption.md`
- `stories.md`
- `facebook-post.md`
- `linkedin-post.md`
- `email-announcement.md`
- `text-message.md`
- `blog-post.md`

Not every listing needs every format — include only what was actually generated for
that launch.
