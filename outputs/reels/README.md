# Reel Outputs

Instagram Reel / YouTube Shorts scripts generated by `prompts/reel-script.md`, for
content not tied to a specific listing launch (listing Reels live in
`outputs/listings/[address-slug]/reel-script.md` instead).

**Naming convention:** `YYYY-MM-DD-[topic-slug].md`

Each file should include the full structure from `prompts/reel-script.md`: hook, setup,
body beats with shot direction, CTA, suggested caption pairing, and estimated length.
